각 면(face)은 평면 그래프의 bounded cell. face-cluster 가 면들을 macro 로 묶고, 서로 다른 macro 사이 공유 간선만 door 로 방향을 갖는다(2색칠). door 를 클릭해 방향을 뒤집으면 해당 macro 를 directed door = arc 1개, free = 양방향 로 본 mixed graph 의 강연결(단일 SCC) 여부를 즉시 재판정한다.

면 단위(macro 없이)로는 면-dual 홀수 사이클 때문에 어떤 방향도 실패(유효 0). macro 병합이 홀수 사이클을 macro 내부로 흡수해 canonical 방향에서 6/6 성공.
